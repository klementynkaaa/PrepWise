# PREPWISE documentation

PREPWISE helps households in Poland build an emergency supply kit. It tells them what to get, how much, and in what order. The app works online and offline, so a household can still use it during a blackout.

These docs summarise the project's working notes. They stay high-level and only go into detail where you need it to build or review the app. When a decision changes, update the matching document in the same change.
